# DentalTravelCost - Zero-Build Static Production

This version is engineered for **Zero-Build, 100% Static Deployment** (matching SolarSavingsHQ).

### Vercel Deployment Instructions:
1. Drag and drop this folder into the Vercel dashboard.
2. In the deployment settings:
   - **Framework Preset**: `Other` (or None)
   - **Build Command**: *Leave blank / Turn off*
   - **Output Directory**: `.` (or leave blank)
3. Click **Deploy**. Your website will go live instantly in seconds with zero build steps or dependency installations.
