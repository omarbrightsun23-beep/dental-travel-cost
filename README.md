# DentalTravelCost — 2026 Production Release

All-in overseas dental and elective surgery travel cost calculator and patient protection benchmark.

## Features
- **Dynamic Cost Calculator:** Real-time multi-currency exchange rates (USD, GBP, EUR, AUD, CAD) with automatic origin detection.
- **True All-In Travel Accounting:** Accounts for surgeon fees, tier-1 implants (Straumann/Nobel Biocare), return flights, recovery hotels, local transfers, 3D CBCT imaging, and contingency buffers.
- **Accredited Global Hubs:** Benchmarks across Mexico (Los Algodones, Tijuana, Cancun), Turkey (Istanbul, Antalya), Hungary (Budapest), Thailand (Bangkok, Phuket), Costa Rica, Poland, Colombia, and Spain.
- **Printable & Shareable Estimates:** Instant formatted clipboard copy and standalone self-contained HTML document downloads.
- **Full Legal & Google Policy Compliance:** Complete GDPR, CCPA/CPRA, and Google AdSense compliant Privacy Policy, Terms & Conditions, Medical Disclaimer, and Cookie Consent banner.

## Local Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
